# M2 — Virtual Campus Social Media Database

**Course:** ISBA 2407, Santa Clara University MSBA

## Business problem

Model data for a virtual campus social-media platform with clients, discussion sites, people, accounts, and posts.

## Concepts represented in the coursework

- CLIENT, PERSON, SITE, ACCOUNT, and POSTING form the initial conceptual model.
- An account connects a person to a particular site.
- POSTING is modeled as a weak entity identified by a composite key consisting of an account identifier and posting number.
- The extended model includes a recursive parent-posting relationship for replies.
- READING captures repeated read events, supporting activity/frequency analysis.
- The design discusses constraints that keep site-related records consistent.

## Skills demonstrated

Entity-relationship design, composite primary keys, weak entities, recursive relationships, cardinality, and integrity constraints.
