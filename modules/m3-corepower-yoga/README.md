# M3 — CorePower Yoga Studio Operations Database

**Course:** ISBA 2407, Santa Clara University MSBA

## Proposed business use case

A conceptual operational database for a multi-location yoga studio business. This is an academic proposal, **not** a description of or access to CorePower Yoga's actual internal database.

## Requirements explored

- Maintain member and employee profiles.
- Represent instructors and studio staff as employee roles.
- Track studios, practice rooms, class types, and scheduled sessions.
- Support memberships, class passes, purchases, and payments.
- Represent bookings, waitlists, cancellations, and attendance.
- Enable operational questions about class demand, room capacity, and access-plan usage.

## Design concepts

The proposed enhanced entity-relationship model includes person/member/employee roles, access-plan subtypes, and bookings that connect members with scheduled class sessions.

## Skills demonstrated

Requirements gathering, business process modeling, EER specialization, entity identification, relationship cardinality, and operational database planning.

## Scope note

This is a portfolio summary of the M3 Phase I proposal and EER modeling work. It does not include instructor materials, the original submission, proprietary data, or implemented SQL.
