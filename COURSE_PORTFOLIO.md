# ISBA 2407 — Database Analysis, Design and Management

A portfolio index of database modeling case studies from the Santa Clara University MSBA program.

These descriptions summarize academic project topics. Original assignment documents, instructor materials, and group submissions are not published here. Any public-facing example SQL is independently prepared and labeled as such.

## M2 — Virtual Campus Social Media Database

**Conceptual design:** A virtual campus social platform with clients, people, sites, accounts, and postings. The design uses a composite key for postings and explores replies and reading-history records.

**Skills:** entity-relationship modeling, weak entities, composite keys, recursive relationships, event tracking, and data-integrity rules.

[Read the portfolio case-study summary](modules/m2-virtual-campus/README.md)

## M3 — CorePower Yoga Studio Operations Database

**Conceptual design:** A proposed multi-location yoga studio database supporting members, staff, access plans, studio rooms, scheduled classes, reservations, and payments.

**Skills:** business requirements analysis, enhanced ER modeling, specialization/generalization, cardinality, and reservation workflow design.

[Read the portfolio case-study summary](modules/m3-corepower-yoga/README.md)

## M4 — Vacation Property Rentals

**Course case study:** EER-to-relational mapping, functional dependencies, 3NF, and a rule preventing overlapping rentals.

**Independent portfolio extension:** [Illustrative PostgreSQL schema](sql/schema.sql) and [analytical queries](sql/example_queries.sql). The example schema is deliberately separate from the original assignment's six-relation design.
